# Azuret-Videos

フリー動画保存用レポジトリ / Free Video Storage Repository

## 概要 / Overview

このレポジトリは、フリーに使用できる動画ファイルを保存・共有するためのものです。

This repository is for storing and sharing freely usable video files.

## 使い方 / How to Use

1. このレポジトリをクローンまたはフォークしてください
2. 動画ファイルを適切なディレクトリに追加してください
3. **必ず動画の著作権情報を明記してください**

1. Clone or fork this repository
2. Add video files to the appropriate directory
3. **Always specify the copyright information for videos**

## 動画の著作権表記について / Video Copyright Attribution

### 重要 / Important

**すべての動画には必ず著作権情報を明記してください。**

**Copyright information must be specified for all videos.**

### 著作権情報の記載方法 / How to Specify Copyright Information

動画ファイルと同じディレクトリに、以下の情報を含むテキストファイル（`COPYRIGHT.txt` または `README.txt`）を作成してください：

Create a text file (`COPYRIGHT.txt` or `README.txt`) in the same directory as the video file with the following information:

```
動画ファイル名: [ファイル名]
著作者: [著作者名]
ライセンス: [ライセンス種類（例：CC0, CC BY 4.0等）、またはパブリックドメイン]
出典: [元のURL等があれば記載]
説明: [動画の簡単な説明]
```

Example:
```
Video filename: example_video.mp4
Author: [Author name]
License: [License type (e.g., CC0, CC BY 4.0) or Public Domain]
Source: [Original URL if applicable]
Description: [Brief description of the video]
```

### ライセンスの例 / License Examples

- **CC0 (Public Domain)**: 著作権を放棄、自由に使用可能
- **CC BY 4.0**: 著作者のクレジット表示が必要
- **CC BY-SA 4.0**: 著作者のクレジット表示と同一ライセンスでの公開が必要
- **MIT License**: MIT ライセンスに準拠

詳細は各ライセンスの規約を確認してください。

For details, please check the terms of each license.

## ディレクトリ構成 / Directory Structure

```
Azuret-Videos/
├── README.md              # このファイル / This file
├── LICENSE                # リポジトリのライセンス / Repository license
└── videos/                # 動画ファイル用ディレクトリ（必要に応じて作成）
    ├── category1/
    │   ├── video1.mp4
    │   └── COPYRIGHT.txt  # 動画の著作権情報
    └── category2/
        ├── video2.mp4
        └── COPYRIGHT.txt
```

## コントリビューション / Contribution

動画を追加する際は：

When adding videos:

1. 適切なフォーマット（MP4推奨）で動画を用意
2. 著作権情報を必ず明記
3. プルリクエストを作成

1. Prepare the video in an appropriate format (MP4 recommended)
2. Always specify copyright information
3. Create a pull request

## 注意事項 / Notes

- 著作権情報が明記されていない動画は削除される可能性があります
- 著作権に違反する動画のアップロードは禁止です
- 不明な点がある場合は、イシューで質問してください

- Videos without copyright information may be removed
- Uploading videos that violate copyright is prohibited
- If you have any questions, please ask in the issues
